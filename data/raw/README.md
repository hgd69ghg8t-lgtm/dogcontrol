# Upload the MCERT data here

Put the dog control statistics workbook(s) from
[MCERT](https://www.mcert.govt.nz/our-work/local-government/dog-control/dog-control-statistics/#latest-release)
in this folder, unchanged, e.g. `Dog-control-statistics-Nov-2025.xlsx`.

**On GitHub:** open this folder, click **Add file → Upload files**, drag the
`.xlsx` in, and commit to the branch.

Every `.xlsx` here is read by `scripts/build_data.py`; other files (like this
README) are ignored. Older releases can stay alongside newer ones.
